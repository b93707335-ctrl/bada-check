# 바다체크 (Bada Check)

해수욕장별 수질·파도·날씨 안전점수와 샤워실 대기 현황을 한 화면에서 확인하는 교육용 반응형 웹앱입니다.

## 주요 기능
- 해수욕장 검색 및 자동완성
- pH, 수온, 탁도, 용존산소, 염분, 파도, 풍속, 이안류, 강수량 등 각 항목 100점 평가
- 수질·해양 안전·날씨 카테고리 점수 및 종합점수
- 샤워실 20개 기준 입장·퇴장 처리
- 20명 초과 시 대기자 자동 전환
- 입장·퇴장 때마다 예상 대기시간 즉시 재계산
- 최근 조회 기록, 즐겨찾기, 현재 위치 기반 가까운 해수욕장 선택

## 실행 방법
프로젝트 폴더에서 `index.html`을 브라우저로 열면 됩니다. 로컬 서버 사용을 권장합니다.

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다.

## 데이터 안내
현재 `js/data.js`에는 시연용 데이터가 들어 있습니다. 실제 서비스에서는 공공데이터 API 또는 자체 서버에서 값을 가져오도록 교체해야 합니다. API 키는 프론트엔드 코드에 직접 넣지 말고 서버 또는 안전한 환경변수에서 관리하세요.

## 실시간 동기화 범위
현재 구현은 같은 브라우저의 `localStorage`를 사용합니다. 같은 브라우저의 다른 탭에서는 `storage` 이벤트로 동기화됩니다. 여러 휴대전화에서 동일한 현황을 공유하려면 Firebase Realtime Database, Supabase 또는 자체 백엔드를 연결해야 합니다.

## 참고 방향
- 블루밸런스: 수질 입력·분석·교육용 안내 구조
- 바다샤워 줄서기: 현재 대기 인원, 예상 대기시간, 이용 가능한 샤워실 표시 구조

두 참고 사이트의 기능을 복사하지 않고 바다체크의 통합 흐름에 맞게 재구성했습니다.
